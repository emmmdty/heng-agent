## 二、根因分析结论（为什么判段作废——先读懂再动手）

### 2.1 已排除的假设

| 假设 | 排除证据 |
|---|---|
| 接线把两臂 transcript 装反 | 真实数据双序装配逐字节核对正确（`ab_pairwise.build_pair_prompt` 的 回复1=A/回复2=B、反序互换） |
| 判词格式问题（缺推理空间等） | CoT+位置中性迭代后 78.3%→70.8%/66.7%，无效；但无回归（格式修复保留） |
| "两臂内容近乎相同导致 judge 无所适从" | **被推翻**：臂间 transcript 相似度中位 0.41 ≈ 臂内 0.33——两臂差异不比同臂两次采样大 |
| judge 挂了/脏输出塌缩 | error 行仅 0-1/24，脏输出全程留名；读数失真不是塌缩造成 |

### 2.2 三层根因（每层有数据）

1. **agent 执行级噪声 ≫ 处理效应（源头）。** 同臂同用例两次采样相似度中位 **0.33**
   （最低 0.16：no-fabrication A0-A1）——mimo-v2.5 每次执行在措辞/推荐/结构/**是否编造参数**
   上随机波动；提示词 diff 只影响少数行为子集。两臂行为分布高度重叠，
   每对比较 = 同一分布的两个随机抽样。
2. **judge 抖动集中在 tie↔decision 边界（机制）。** 24 对 × 4 裁决分型：
   **10 对稳定全平**（judge 能一致判平）、**3 对稳定决定**、**11 对边界抖动（46%）**。
   抖动 = 位置敏感成分（landed-price 对0、memory-write 对0 两轮都呈 `ab=b/ba=tie`）
   + 轮间采样噪声（同提示词同序两轮 **29.2% 对翻转**——该网关温度 0 非确定性）。
3. **处理效应维度不在成对判据视野里（放大器）。** 候选的两个效应维度
   （确认卡完整性、算式展示）真实存在（算式展示 compare-two A=2/B=0、de-minimis A=5/B=1），
   但成对判据只有通用四条（事实/边界/回答/表达）——两份都正确时，
   算式展示风格差异不足以让 judge 稳定抉择。

### 2.3 隐藏信号（重要，但当前范式无法认证）

边界抖动对里的决定性裁决 **B 占 80%（24:6）**；Arena 式计票 B 胜率 67%（28/42，≈2.1σ）。
判词显示 B 胜的理由是**真实质量差异**：A 臂抽样编造了"-45dB 降噪/40h 续航"等参数、
或漏报到手价——但这是**分布级差异**（A 的 k1 编造、k0 不编造），不是逐对确定差异。
3 对可靠核心方向 2:1（A2/B1），无逐对信号。
含义：候选可能真的略优（编造倾向更低），但"逐对一致性 + 小 n"范式认证不了分布级差异。
