1. **模型三选**：mimo-v2.5 被测 / **longcat-2.0 唯一全职 judge**（12000 预算、
   `--judge-votes 3`、并发 4）/ deepseek-v4-flash 仅预登记小样本双 judge 证据

   **不要用其他任何模型。**
2. **改 `app/`（含 heng.yml）必重启 uvicorn**；起服务顺序 = 隧道 → `make health`
   → 起服 → `grep "向量索引就绪"`。
3. **烧 token 顺序**：`--only` 1-2 条 → 小样本 → 放大；**每次烧配额前 subagent
   code review**（审接线缺口与静默塌缩）；判据/统计/解析器零 LLM 先做完；
   TDD 先红后绿。
4. **降级路径必须留因**（`describe_error`），脏输出绝不静默塌缩。
5. **每轮双验收**：subagent review + 指标快照；按里程碑提交；**push 由用户**。
6. 引用基线钉死文件名（R8 = `eval/report-20260905-142017.json`）；产物前缀
