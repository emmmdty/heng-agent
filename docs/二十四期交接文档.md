## 六、纪律与风险（本期特有的）

1. **判据与代码联动是最大风险面**：GBX 出现在判据文本（confirmation、cases.yaml rubric、
   judge 评分细则）与**测试断言**两层，漏改任何一层的外观都是"全绿但判据失效"——
   V3 验收必须独立 grep 复核，不能只看测试绿。
2. **提示词文件改名（globex.yml → heng.yml）会改变 prompt_fingerprint**：`/health` 自报新指纹，
   评测报告与方差工具自动按新配置分组——无需也不得手工对齐旧指纹。
3. **历史文档的数字不改**：改写表述时，读数、期数、文件名引用保持原值
   （私有化改的是"叫什么"，不是"做过什么"）。
4. **不改写 git 历史**；push 前跑一遍敏感信息扫描（密钥/内网路径）。
5. 常规地雷清单（代理 502、pkill 自杀、Qdrant 锁、`__del__` 语义等）见 `docs/交接文档.md` 第六节——本期基本用不到，但服务别乱重启（迁移期间不需要跑服务、不需要打模型）。
